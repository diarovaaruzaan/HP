1. Массив фиксированный по размеру, память на стеке, быстро по индексу.
   Динамические структуры гибкие, память в куче, можно менять размер, но сложнее управлять.
2. Указатель - это переменная, которая хранит адрес другой переменной. 
3. Стек — LIFO, последний пришёл — первый ушёл. Очередь — FIFO, первый пришёл — первый ушёл.
4. Преимущества односвязных списков то, что легко добавлять/удалять элементы, не нужен фиксированный размер, 
   а недостатки доступ по индексу медленный, память на указатели нужна, сложнее управлять.
5. Для одного элемента — delete, для массива — delete[]. В списках/деревьях освобождаем каждый элемент вручную.
6. Чтобы потоки не ломали память, не было ошибок и утечек. Нужно знать, какие данные общие, а какие у каждого потока.
7. Используем reduction(+:sum) для суммы, reduction(min:min_val) для минимума, reduction(max:max_val) для максимума. Потоки считают локально, потом объединяется.
8. Большие массивы считаются быстрее, потому что работа делится между ядрами.
   Малые массивы иногда даже медленнее из-за накладных расходов.
