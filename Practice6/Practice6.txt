1. Global — общая память устройства.
   Local — быстрая память внутри рабочей группы.
   Private — память одного потока.
   Constant — память только для чтения.
2. Global — сколько всего потоков.
   Local — сколько потоков в одной группе.
3. OpenCL работает на CPU и GPU разных производителей.
   CUDA работает только на GPU NVIDIA.
4. Кросс-платформенность.
   Один код для разных устройств.
   Не зависит от производителя.
